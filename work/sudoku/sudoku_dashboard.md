# Sudoku Dashboard

## 実装方針

- 9x9の標準的な数独を実装する。
- 難易度（Easy, Medium, Hard）を選択可能にする。
- メモ機能（Pencil marks）を搭載する。
- 同一数字のハイライト、選択中の行列・ブロックのハイライトなどのQOL機能を充実させる。
- デザインは他のゲームと統一し、プレミアムな外観にする。
