# Catan AI Logic Specification

本ドキュメントは、カタンAI（CPUプレイヤー）の意思決定ルーチン、思考パターン、および優先順位に関する詳細仕様である。

---

## 1. 思考ルーチンの全体構造

AIの意思決定は以下の順不同で評価され、最も期待値の高いアクションが選択される。

$$Decision = CommonTactics + PersonaStrategy$$

1.  **共通戦術 (Common Tactics)**: 全AI共通の「勝利に直結する行動」「危機回避」「妨害」のロジック。
    - 例: 勝利確定時の行動、盗賊の移動、バースト回避。
2.  **ペルソナ戦略 (Persona Strategy)**: AIの性格ごとに異なる「資源の価値基準」や「目指す勝利条件」。
    - 例: 道を伸ばすか、都市化するか、発展カードを引くか。

---

## 2. 共通思考ルーチン (Common Logic)

AIのタイプに関わらず、以下の状況では共通の判断基準を用いる。

### 2-1. 盗賊 (The Robber)

ダイスで「7」が出た、または「騎士(Knight)」カードを使用した場合の処理。

**移動先の優先順位**:

1.  **安全地帯回避**: 自身の開拓地/都市が隣接しているタイルには絶対に配置しない。
2.  **トップ叩き**: 現在「最も優勢なプレイヤー」が資源を得ているタイルを狙う。
    - _優勢判定基準_: 公開勝利点 > 都市数 > 資源カード保持数 > 発展カード保持数
3.  **高確率ブロック**: ターゲットの土地の中で、数字の確率（ドット数）が最も高いタイル（6, 8など）を優先。
4.  **資源強奪**: ブロックしたタイルに隣接するプレイヤーから、資源を奪う（ターゲット優先）。

### 2-2. 発展カードの使用 (Play Dev Card)

ターン開始時、またはフェーズ中に以下の条件で使用を検討する。

1.  **勝利宣言**: そのカードを使うことで勝利点が10点に到達する場合、即座に使用する（VPカード含む）。
2.  **騎士 (Knight)**:
    - 自身の重要な資源タイルに盗賊がいる場合、即座に使用して排除する。
    - 「最大騎士力(Largest Army)」を獲得でき、かつ保持できそうな場面。
3.  **独占 (Monopoly)**:
    - 特定の資源が大量に産出された直後（ログ参照）。
    - 自身が建設に必要で、かつ枯渇している資源を宣言する。
4.  **街道建設 (Road Building)**:
    - 建設によって新しい開拓地が作れる場合（2本分のコスト節約）。
    - 「最長交易路(Longest Road)」を獲得、または防衛できる場合。
5.  **発見 (Year of Plenty)**:
    - 都市化や開拓地建設のために、資源がちょうど2つ不足している場合。

## 3. AIペルソナ（戦略パターン）

AIは以下の3つのパターンのいずれかが割り当てられ、それぞれ資源に対する評価値（Weight）が異なる。

### Type A: 拡大再生産型 (Land Expansion)

**「道と開拓地」**による広範囲な領土拡大を最優先し、物量で勝利を目指すタイプ。
「最長交易路(Longest Road)」への意識が高い。

- **重要資源**: **土(Brick)**, **木(Wood)** 優先
- **資源優先度**: `土(1.3) > 木(1.3) > 麦(1.0) > 羊(1.0) > 鉄(0.8)`
- **初期配置方針**:
    - 土・木の産出量が安定している場所（数字の確率が高い場所）。
    - 2手目は、1手目で確保できなかった資源を補完できる場所。
- **建設優先順位**:
    1.  **開拓地**: 建設可能な場所があれば最優先。
    2.  **道路**: 新しい建設候補地へ向かうための道路建設。ただし土、木は最低1個ずつは確保する。
    3.  **都市化**: 資源が余っていれば実施。
    4.  **発展カード**: 手札調整などで受動的に購入。

### Type B: 都市・開発型 (City Development)

**「都市化と発展カード」**による効率化を重視するタイプ。
「最大騎士力(Largest Army)」への意識が高く、狭い領土でも生産力で勝る。

- **重要資源**: **鉄(Ore)**, **麦(Wheat)** 優先
- **資源優先度**: `鉄(1.4) > 麦(1.2) > 羊(1.0) > 土(0.8) > 木(0.8)`
- **初期配置方針**:
    - 鉄・麦の産出量が確保できる場所を最優先。
    - 初期配置の開拓地を早期に都市化することを狙う。
- **建設優先順位**:
    1.  **都市化**: 生産力の強化を最優先。
    2.  **発展カード**: 鉄・麦・羊が揃えば積極的に購入。
    3.  **開拓地**: 3の手として、余力があれば行う。
    4.  **道路**: 必要最低限（港への接続など）に留める。

### Type C: 期待値最大化型 (Expectation Maximization)

特定の資源種別にはこだわらず、**「資源獲得確率（Pip数）」の合計最大化**を最優先するバランス型。
豊富な資源量を背景に、銀行や港での交換を多用して柔軟に立ち回る。

- **重要資源**: **バランス型**（または3:1港、専門港）
- **資源優先度**: `全資源(1.0)` （状況により不足資源の価値を動的に上げる）
- **初期配置方針**:
    - 資源の種類に関わらず、数字の確率（ドット数）の合計値が最も高い交差点を選択。
    - 数字が強い場所を取れるなら、資源が偏っても構わない（港で変える前提）。
- **建設優先順位**:
    - 状況に応じ、最も「勝利点効率」が良いアクションを選択する。
    - 初期は開拓地数重視、中盤以降は都市化・カード購入へシフトする柔軟性を持つ。

## 4. 初期配置ロジック (Setup Phase)

初期配置は以下の評価関数 $Score(I)$ が最大となる交差点 $I$ を選択する。

$$Score(I) = \sum_{t \in AdjacentTiles(I)} (Probability(t) \times Weight_{Persona}(Resource(t))) - Penalty(I)$$

- $Probability(t)$: タイルの数字確率（2/12=1点, ..., 6/8=5点）。
- $Weight_{Persona}(r)$: ペルソナごとの資源重要度（前述）。
- $Penalty(I)$:
    - 港がない海岸沿い: -2点
    - 発展性がない（行き止まり等）: -1点

**2手目の配置補正**:
1手目で確保した資源とのバランスを考慮し、1手目で得られない資源（不足資源）の評価値 $Weight$ を一時的に +0.5 して再計算する。

## 5. 建設・行動ターンロジック (Main Turn)

AIの手番では、以下のフローで行動を決定する。

1.  **勝利判定**:
    - 現在のアクションで勝利可能か？ → Yesなら実行して勝利。
2.  **盗賊/カード処理**:
    - 「騎士」を使うべきか？（共通思考参照）
3.  **建設アクション**:
    - 資源が足りている建設物の中で、ペルソナごとの優先順位に従って実行。
    - _建設場所の選定_:
        - 開拓地: $Score(I)$ が最も高い空き地。
        - 道: 最も高い評価値の空き地に向かう最短ルート。
4.  **トレード/交換**:
    - 建設したいが資源が足りない場合、銀行/港交換を検討（後述）。
5.  **ターン終了**:
    - これ以上有効なアクションがない場合、ターンを終了。

---

## 6. トレード・交渉ロジック (Trading)

### 6-1. 銀行・港トレード (Bank/Port)

- **実行基準**:
    - 交換を行うことで、そのターン中に「建設」や「カード購入」が**実行可能になる場合(確定行動)**のみ行う。
    - バースト（手札8枚以上）回避のために、消費目的で行う場合もある。
- **優先順位**:
    1.  専門港 (2:1)
    2.  一般港 (3:1)
    3.  銀行 (4:1)

### 6-2. プレイヤー間トレード (Player Trade)

AIは以下の基準で、人間プレイヤーからの交換提案を承諾する。

$$Value(Get) > Value(Give) + RivalryCost$$

- $Value(r)$: ペルソナごとの資源評価値。現在不足している資源は評価が高くなる。
- $RivalryCost$: 相手がトップ（または勝利直前）の場合に加算されるコスト。
    - 相手が9点の場合: 取引拒否 (Cost = Infinity)
    - 相手がリードしている場合: Cost = high (かなり有利な条件でないと受けない)

**タイプ別傾向**:

- **Type A**: 土・木を渡すのを渋る。「土・木」を求めて「羊・鉄」を出す傾向。
- **Type B**: 鉄・麦を渡すのを渋る。「鉄・麦」を求めて「土・木」を出す傾向。
- **Type C**: 1:1交換なら比較的柔軟に応じる。自分が損しない（枚数が減らない、または不要牌処理）なら受ける。
