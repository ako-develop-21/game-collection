# カタンの開拓者 1人プレイシミュレータ 設計書

## 1. プロジェクト概要
本プロジェクトでは、ボードゲーム「カタンの開拓者」を1人でプレイ（コンピュータ対戦）できるシミュレータを実装する。UI/UXは直感的で洗練されたものとし、ゲームロジックは標準ルールに準拠する。

## 2. ゲーム仕様

### 2.1 盤面構成
- **ヘックスタイル**: 合計19枚（森林4、草原4、畑4、山地3、丘陵3、砂漠1）。
- **数字チップ**: 2〜12のチップ（7を除く）をアルファベット順またはランダムに配置。
- **港**: 海岸線に特定資源の3:1または自己資源の2:1交換が可能な港を配置。

### 2.2 ゲームフロー
1. **初期配置フェーズ**: 各プレイヤーが2つの「開拓地」と「街道」を設置。2つ目の開拓地周辺の資源を初期手札として獲得。
2. **手番サイクル**:
   - **ダイスロール**: 2d6を振る。
   - **資源産出**: 出た目に対応するタイルの隣接者に資源を配布。
   - **交渉 (Trade)**: プレイヤー間または銀行(4:1等)との資源交換。
   - **建設 (Build)**: 資源を消費して街道、開拓地、都市、発展カードを構築。
   - **発展カードの使用**: 騎士カードや特殊カードの発動。
3. **終了判定**: いずれかのプレイヤーが10ポイント（勝利ポイント）に到達した時点で終了。

### 2.3 1人プレイ（AI）仕様
- **対戦相手**: コンピュータ 3名。
- **AIアルゴリズム (簡易版)**:
  - **建設優先度**: 開拓地 > 都市 > 発展カード > 街道。
  - **リソース管理**: 必要なリソースが不足している場合、銀行との交換を検討。
  - **進路妨害**: プレイヤーの最長交易路を阻害するように街道を引く。

## 3. 技術設計

### 3.1 コンポーネント構造
- `CatanGame.vue`: ゲーム全体のプロトコルと状態管理。
- `HexBoard.vue`: SVGを用いたカタン盤面のレンダリング。
- `ResourceBar.vue`: プレイヤーの所持資源とポイントの表示。
- `ActionPanel.vue`: ダイス、建設、トレード等の操作ボタン。

### 3.2 状態管理 (useCatan.ts)
- `board`: タイルの種類、チップ、建設物の座標データ。
- `players`: 4人のプレイヤー情報（リソース、ポイント、建設物リスト）。
- `gameState`: 現在の手番、フェーズ（配置、通常、終了）。

## 4. UI/UX デザイン案
- **ビジュアル**: ガラスモフィズムやアニメーションを活用し、プレミアムな雰囲気。
- **レスポンシブ**: PCブラウザでの操作をメインとし、ドラッグ＆ドロップまたはクリックで建設場所を選択。

## 5. 実装スケジュール
- **ステップ 1**: 盤面のランダム生成と表示。
- **ステップ 2**: ダイス機能と資源配布ロジック。
- **ステップ 3**: 建設アクション（バリデーション含む）。
- **ステップ 4**: 簡易AIの思考ルーチン。
- **ステップ 5**: デザインのブラッシュアップと調整。
