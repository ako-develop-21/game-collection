# Catan AI 実装計画書 (AI Implementation Plan)

このドキュメントは、`catan_ai_logic.md` に基づく AI 強化の実施ステップを管理します。

## 既知の状態

- 現在の AI はランダムに近い行動をとる。
- 初期配置もランダム。
- トレード受諾ロジックは存在するがシンプル。

---

## フェーズ 1: ペルソナと評価基準の実装 [x]

- [x] `Player` インターフェースに `persona` フィールドを追加
- [x] 各ペルソナごとの資源評価定数 (Weight) の定義
- [x] 座標・タイルに基づいた「資源期待値」計算ユーティリティの実装

## フェーズ 2: セットアップ（初期配置）の高度化 [x]

- [x] 指定された評価関数 $Score(I)$ による交差点スコアリングの実装
- [x] 2手目の配置における「不足資源補正」ロジックの実装
- [x] 港タイルの評価加点
- [x] `aiPlayTurn` の setup フェーズをこれらに差し替え

## フェーズ 3: メインターンの建設戦略 [x]

- [x] 「目標開拓地」選定ロジックの実装（`findBestTargetNode`）
- [x] 目標地点への最短経路（エッジのリスト）を計算する機能の実装
- [x] 建設判断の高度化:
    - [x] 最優先: 勝利確定アクション
    - [x] 次点: 都市化（生産力強化）
    - [x] その次: 目標地点での開拓地建設
    - [x] 道の建設ルール:
        - 基本は目標地点に向かって建設する。
        - **温存（建設停止）の条件**: すでに開拓可能な土地まで道が繋がっている場合（バースト回避時や最長不倒の防衛・獲得時を除く）。
- [x] `aiPlayTurn` のメインターン（建設セクション）を上記ロジックに差し替え

## フェーズ 4: トレード・交渉の洗練 [x]

- [x] 銀行・港での 4:1 / 3:1 / 2:1 交換の戦略的実行（建設可能になる場合のみ）
- [x] 人間からのトレード受諾ロジックの更新 ($Value$ 計算にペルソナを反映)
- [x] 相手の勝利点に基づく `RivalryCost` (対抗コスト) の導入

## フェーズ 5: 妨害と特殊カード [x]

- [x] 盗賊の移動先選定ロジック（優勢プレイヤーのブロック）
- [x] 発展カード（街道建設、独占、発見、騎士）の戦略的使用
- [x] バースト（手札8枚以上）回避のための交換・建設意識向上
- [x] 全体の動作テストと調整
