# カタンの開拓者 1人プレイシミュレータ 実装計画書

開発における手戻りを最小限にするため、以下の6つのフェーズに分けて実装を進める。

## フェーズ 1: 盤面生成と描画の基盤

**目的**: ゲームの土台となる盤面を生成し、画面に表示する。

- **実装内容**:
    - タイル、交差点(Node)、辺(Edge)のデータ構造定義。
    - タイル配置アルゴリズム（19枚のヘックスタイル）。
    - 数字チップ(2-12)のランダム配置ロジック。
    - SVGを使用した `HexBoard.vue` の作成。
- **完了条件**: ブラウザ上で標準的なカタンの盤面が正しく表示される。

## フェーズ 2: ゲーム状態管理とダイス/資源配布

**目的**: ゲームの進行状態を管理し、ダイスによる資源産出を可能にする。

- **実装内容**:
    - `useCatan.ts` による状態管理（リソース、手番、フェーズ）。
    - ダイスロール機能。
    - 出た目に対応する資源を配布するロジック。
- **完了条件**: ダイスを振ると、関連する資源が増加することが確認できる。

## フェーズ 3: 建設ロジックとバリデーション

**目的**: プレイヤーがルールに従って建設を行えるようにする。

- **実装内容**:
    - 街道、開拓地、都市、発展カードの建設機能。
    - コスト消費ロジック。
    - 建設バリデーション（街道の接続、開拓地の距離ルール等）。
- **完了条件**: 正当な場所のみに建設でき、資材が正しく消費される。

## フェーズ 4: 初配置フェーズとターン管理

**目的**: ゲーム開始から終了までの流れを完成させる。

- **実装内容**:
    - ゲーム開始時の初期配置（2件ずつの開拓地と街道）ロジック。
    - ターン終了と手番交代の仕組み。
    - 銀行および港とのトレード(4:1, 3:1, 2:1)の実装。
- **完了条件**: 初期配置から始まり、ターンを回してゲームを進行できる。

## フェーズ 5: ソロプレイ用AIの実装

**目的**: 1人で遊べるように、対戦相手であるコンピュータの思考を実装する。

- **実装内容**:
    - コンピュータ3名の自動手番処理。
    - 建設優先度に基づいた行動選択ロジック。
    - 基本的な資源交換（銀行とのトレード）判断。
- **完了条件**: 自分以外の3つの勢力が自動で開拓を進める。

## フェーズ 6: 勝利判定と UI/UX ブラッシュアップ

**目的**: ゲームを完成させ、視覚的な品質を高める。

- **実装内容**:
    - 勝利ポイント(10点)の計算とゲーム終了表示。
    - 最長交易路、最大騎士力の判定。
    - ガラスモフィズムやアニメーションを用いた演出追加。
- **完了条件**: 誰かが10点に達した際にゲームが終了し、演出が実行される。
